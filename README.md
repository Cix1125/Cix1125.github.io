用编辑器全局搜索 `【` ，把下面这些全部换掉。**没换完不要投出去** —— 带 `【】` 的简历会直接暴露「这是模板」。

| 位置 | 内容 |
|---|---|

## 三、部署（让链接能发出去）

### 方式 A：GitHub Pages（推荐，免费，链接好看）
1. 注册 GitHub，新建仓库 `portfolio`
2. 把 `index.html` 和 `demo/`、`cases/` 上传
3. 仓库 Settings → Pages → Source 选 `main` 分支 → Save
4. 等 1 分钟，链接形如 `https://你的用户名.github.io/portfolio/`

### 方式 B：Vercel / Netlify（拖拽即可）
把整个文件夹拖进网站，几十秒出链接。

### 方式 C：最省事（先救急）
把 `index.html` 直接发给对方，或用微信「文件传输助手」发给自己 —— 单文件、无外部依赖，**对方双击就能看**。DEMO 也在同一个文件夹里，能点开。

> ⚠️ 注意：`index.html` 里 Demo 链接是相对路径 `demo/inventory.html`。
> **只发一个 html 文件的话 Demo 会点不开**，要么整个文件夹打包发，要么用方式 A/B 部署。

### 案例 PDF 怎么来的

`cases\PDF\` 里的 PDF 是从 md 生成的，**改了 md 重跑一次就行**：

```powershell
cd 桌面\FDE作品集
python cases\_生成PDF.py
```

脚本会顺便报出每份还剩多少 `【】` 占位符。

> ⚠️ **现在只有案例 04 的 PDF 可以直接发出去。**
> 01 还剩 10 处、02 还剩 1 处、03 还剩 6 处 `【】` 占位符（都是要你填真实数据的）。
> 填完 md 再重跑脚本，PDF 就干净了。
